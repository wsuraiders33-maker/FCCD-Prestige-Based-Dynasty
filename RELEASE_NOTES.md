# FCCD Prestige-Based Dynasty v1.0.3 — Release Notes

Version 1.0.3 is the standalone Windows/Steam FCCD 1.6.5 update to RC7/v1.0.2. It preserves prestige roster caps, college eligibility and previous transfer/UI improvements.

## New in v1.0.3

- Annual **adaptive recruiting-class target** based on participating, non-FCS teams' current prestige-adjusted roster caps: `min(original class size, round(total roster capacity * 30/85))`.
- Same randomized trimming for oversized **game-generated and imported custom** recruiting classes; original skills and potential preserved.
- AI **position-room checks** using returning-player projections and prior commitments to reduce over-recruiting at constrained positions, including kickers.
- Matching safeguards for **user auto recruiting**; manual recruiting remains unchanged. Existing commitments and roster members are not automatically removed.
- Small-cohort gem-selection guard.

## Features retained

- Ten prestige roster caps: **34, 40, 45, 51, 57, 62, 68, 74, 79, 85**.
- v1.0.1 AI depth/roster-repair protections.
- v1.0.2 transfer shortlist and Top Five + User recruiting preview.
- College redshirt and normal eligibility rules.

## Validation

- 72-school Northmont universe, 2025: roster capacity **4,474**, target **1,579**; imported 2,500-player source trimmed to **1,579**.
- Same universe, 2026: roster capacity **4,451**, target **1,571**; imported 3,500-player source trimmed to **1,571**. Matched source recruits retained their attributes.
- 148-school Dartmouth test: adjusted targets **2,898** then **2,870**, observed annual rollover within roster caps and satisfactory preseason positional coverage.
- Public package retains the tested private v1.0.3 engine payload byte-for-byte. The newly public-labeled ZIP was checked offline for package integrity, but has not been independently run through Windows install and restore in this environment.

## Install

Download `FCCD_Prestige_Based_Dynasty_v1_0_3_Public_Release.zip` from **Assets**, extract the entire archive and run the top-level `INSTALL.bat`, followed by `VERIFY.bat`. To revert run the same archive's `RESTORE.bat`. This is a **patch-only** archive, not GitHub's autogenerated source ZIP. Requires the exact supported Windows/Steam FCCD 1.6.5 files.

**Do not install over the published v1.0.2 mod**: restore v1.0.2 to Steam stock first. Earlier one-click v1.0.3 private installations are recognized. Do not stack unrelated mods.
